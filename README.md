## Riguardo il Progetto

Questo è stato il mio ultimo progetto di quinta superiore, mi ha aiutato a consolidare le basi di full-stack development. 

Si tratta di un sito web per tenere traccia del proprio progresso nell'arte del tricking e prevede l'avanzamento in tre macro-aree:

- Power Moves
- Caricamenti
- Avvitamenti

Permette di visualizzare trick a difficoltà crescente in una forma ad albero.
Per ogni salto sono disponibili dei video tutorial che ho ritenuto utili per l'apprendimento.

Tramite autenticazione è possibile salvare il proprio progresso e condividere dei commenti, visibili ad altri utenti, riguardo i diversi trick.

## Requisiti e Installazione

Per avviare il progetto in locale, è necessario creare un ambiente virtuale e installare i pacchetti richiesti.

1. Crea un ambiente virtuale:

```
python -m venv venv
```

2. Attiva l'ambiente:

  Su Windows: 

```
venv\Scripts\activate
```

  Su macOS/Linux: 
  
```
source venv/bin/activate
```

3. Installa le dipendenze:

```
pip install -r requirements.txt
```

## Avvia il server di sviluppo:

```
python manage.py runserver
```

## About the project

This has been my last high school project and it helped me consolidate full-stack development basics.

It is a website designer to track personal progress in the art of tricking, featuring progression across three main macro-areas:

- Power Moves
- Setups
- Twists

It allows users to visualize tricks of increasing difficulty through a tree structure.
For each trick, tutorial videos are available that I found useful for learning.

Through authentication, users can save their progress and share comments about different tricks, which are visible to other users.

### Tester Account:

Since the most interesting section of the website is only accessible after authentication, creating an account is required. To make it easier for those who simply want to explore the project, I am providing the credentials of an already existenting dummy user:
